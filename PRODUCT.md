# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Book enthusiasts browsing Japanese and English BookWalker series.

## Product Purpose

An alternative series view with useful book metadata, page statistics, and
release history. Book browsing leads; comparisons and predictions support
exploration. Data editing is a manual repair for parsing failures.

## Operating Context

A React userscript on BookWalker JP and US. The original storefront remains
accessible. Development uses a watched userscript bundle with automatic browser
reload.

## Capabilities and Constraints

Existing series fetching, covers, authors, publishers, release dates, page
counts where available, comparison, prediction, and manual corrections. Do not
invent prices, availability, or missing page counts. Preserve storefront
navigation and styling.

## Brand Commitments

Better Bookwalker. User delegated the final choice between blue and a warm
neutral/teal identity. User values polished UX and the useful cover-led
structure of the redesigned US storefront.
